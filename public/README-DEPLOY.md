# วิธีติดตั้งหน้า ผรม. + ลูกค้า เข้ากับ ev-dashboard-public

ไฟล์ในนี้วางทับไฟล์เดิมใน repo `ev-dashboard-public` ตาม path ที่ตรงกัน:

- `server.js` -> ทับที่ root ของ repo
- `public/contractor.html` -> ไฟล์ ผรม. (อัปเดต: ปุ่ม "ส่งขออนุมัติเข้างาน")
- `public/client.html` -> ไฟล์ใหม่ (พอร์ทัลลูกค้า)
- `public/auth-guard.js` -> กันไม่ให้ ผรม./ลูกค้า หลุดเข้าไปหน้า admin
- `public/app.js` -> เพิ่มการเด้งบัญชี ผรม./ลูกค้า ออกจากแดชบอร์ด
- `public/report.html`, `public/planner.html` -> เพิ่ม auth-guard

## บัญชี 3 ระดับตอนนี้
| Role | รหัสเริ่มต้น | เห็นอะไรได้บ้าง |
|---|---|---|
| admin | `EV-TEAM-2026` | ทุกอย่าง (แดชบอร์ด, Planner, Report, ข้อมูล ผรม.ทั้งหมด) |
| contractor (ผรม.) | `EV-CONTRACTOR-2026` | เฉพาะ `/contractor.html` และข้อมูลของทีมตัวเอง |
| client (ลูกค้า) | `EV-CLIENT-2026` | เฉพาะ `/client.html`: ดู Diary ทุกฉบับ (อ่านอย่างเดียว) + อนุมัติ/ไม่อนุมัติ "แผนก่อนวันเริ่มงาน" |

เปลี่ยนรหัสได้ผ่าน Railway → Variables: `EV_CONTRACTOR_INVITE_CODE`, `EV_CLIENT_INVITE_CODE`
รหัสใหม่จะถูกเติมให้อัตโนมัติตอน deploy แม้ data เดิมจะยังไม่มีก็ตาม (ไม่กระทบโครงการ/ข้อมูลเดิม)

## Flow การขออนุมัติเข้างาน (ใหม่)
1. ผรม. กรอก "แผนก่อนวันเริ่มงาน" แล้วกด **"ส่งขออนุมัติเข้างาน"**
   → ระบบตั้งสถานะเป็น `รออนุมัติ` โดยอัตโนมัติ (ผรม. กำหนดเองไม่ได้)
2. ลูกค้าเข้า `/client.html` แท็บ "อนุมัติเข้างาน" จะเห็นรายการที่รออนุมัติ (มีตัวเลขแจ้งเตือนที่แท็บ)
   กดดูรายละเอียด แล้วเลือก **อนุมัติเข้างาน** หรือ **ไม่อนุมัติ** พร้อมใส่หมายเหตุได้
3. ผรม. เห็นสถานะอัปเดตในประวัติของตัวเอง (⏳ รออนุมัติ / ✅ อนุมัติแล้ว / ❌ ไม่อนุมัติ)
4. แอดมิน (`EV-TEAM-2026`) ก็อนุมัติแทนลูกค้าได้เช่นกัน (ผ่าน API เดียวกัน)

หมายเหตุ: ลูกค้าเห็นเฉพาะ Diary + แผนงาน (ไม่เห็น Checklist ความปลอดภัยภายใน) และแก้ไข/ลบข้อมูลของ ผรม. ไม่ได้ — ทำได้แค่อนุมัติ/ไม่อนุมัติแผนเท่านั้น

## Deploy
1. คัดลอกไฟล์ในนี้ทับใน local clone ของ repo `ev-dashboard-public`
2. `git add -A && git commit -m "Add contractor + client portals with site-entry approval" && git push`
3. Railway deploy อัตโนมัติ
4. ทดสอบที่ `/contractor.html` (รหัส EV-CONTRACTOR-2026) และ `/client.html` (รหัส EV-CLIENT-2026)

ทดสอบครบใน sandbox แล้ว: แยก role ถูกต้อง / plan ตั้งสถานะ pending อัตโนมัติ / client เห็นเฉพาะ diary+plan / client อนุมัติ-ไม่อนุมัติได้ / ผรม.อนุมัติเองไม่ได้ (403) / client สร้าง record เองไม่ได้ (403)
